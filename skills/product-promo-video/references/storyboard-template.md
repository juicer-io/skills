# Storyboard template

Save as `workspace/<slug>-video-build/storyboard-<LANG>.md`.
`templates/mcp-video/storyboard-EN.md` is a complete example.

```markdown
# <Feature> video for <placement> · Storyboard (<LANG>)

**Date:** YYYY-MM-DD · **For:** <who asked, where it will be embedded>
**Status:** storyboard for review. Nothing rendered yet.

**Format:** ~<nn> s · <1920×1080 (16:9) / 1080×1920 (9:16) / 1080×1080 (1:1) / 1080×1350 (4:5)> MP4 · motion graphics, no voiceover, no presenter · on-screen text carries the story · no setup steps
**Look:** <brand colours> (references/brand-video-spec.md): <one line>
**UI:** <neutral AI chat window / product dashboard mockup / the feature on an example site / ...>
**Data:** <made-up example brand, labelled "Example data" / real posts about <brand>, pulled <date>, window "<this week / today>", searches and links in `sources.md`> · **Published on:** <public channels / internal only>
**Use cases:** <2–3, and where they come from (customer requests, help article, feature page)>

---

## Scene 1 · Hook (0–5 s)
<what moves>
**On screen:** <exact text>

## Scene 2 · The idea (5–9 s)
...

## Scene 3 · Use case 1: <name> (9–22 s)
> <the exact prompt or action shown>

<what the answer / UI shows, with the example numbers>
**Caption:** <one line, official feature name in the label>

...

## Scene N · Outro (…–… s)
**On screen:** <line>
<end card>

---

## Open for review
- <claims you are unsure about, platform names, plan gating, music, language versions>
```

Rules for the scene budget (≤ 60 s): hook 4–5 s, concept 4 s, each use case 10–14 s, outro 5–6 s.
One idea per use case, one insight line per answer ("Start here: …"), captions that name the
benefit, not the feature.
